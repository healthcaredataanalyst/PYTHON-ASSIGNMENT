# Python Assignment 1 - Data Structures

## Project Overview

This project demonstrates basic Python data structures and operations using Strings and Tuples.

## Topics Covered

### Strings
- String concatenation
- String indexing
- String slicing
- Reverse a string
- Uppercase and lowercase
- Capitalize
- Count characters
- Replace words

### Tuples
- Tuple creation
- Tuple concatenation
- Tuple repetition
- Tuple indexing
- Tuple slicing

## File

`assignment1.py` contains the Python code for the assignment.

## How to Run

Run the following command:

python assignment1.py
